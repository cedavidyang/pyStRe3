# Python-based Structural Reliability Analysis

The pacakge was originally developed with Python2 and has since updated to Python3. It is modeled after [FERUM](http://faculty.ce.berkeley.edu/adk/software.html). The original reference (FERUM 3.1) is no longer available, but alternative versions can be found below:

* [FERUM 4.1](https://ferum.limos.fr/index.html)
* TNO custom version: [repo](https://github.com/TNO/custom_FERUM)
